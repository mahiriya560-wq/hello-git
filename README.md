# Ecart Website

Ecart is an online shopping website where users can browse products, explore different categories, and shop for their favorite items.

## What I Learned
Practiced Git and GitHub commands such as git init, git add, git commit, and git push.
Learned how to create and structure a website using HTML, CSS, and JavaScript.
## How to Run
Download or clone the project repository.
Open the project folder in VS Code.
Run the hello.py file using the command below:
bash
python hello.py


Note: If you are using Python 3 with a different command, use python3 hello.py.
